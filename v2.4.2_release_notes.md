# KASP v2.4.2 Sürüm Notları / Release Notes

## 🇹🇷 Türkçe Sürüm Notları (v2.4.2)

### 🚀 Çok Katmanlı Çevrimdışı Şifre Kurtarma ve Güvenlik Güncellemesi

KASP v2.4.2 sürümü, endüstriyel tesisler ve internet erişimi bulunmayan (air-gapped) çalışma sahalarında şifre unutulması ve kilitlenme risklerine karşı **100% yerel çalışan çok katmanlı şifre kurtarma mimarisi** ve yönetim araçlarını sunar:

#### 1. Güvenlik Sorusu ve Yanıtı ile Kurtarma (Security Question & Answer)
* **Kullanıcı Tanımlı Güvenlik Soruları:** Kullanıcılar profil veya güvenlik ayarlarından hazır şablon sorulardan birini seçebilir veya kendi özel sorularını belirleyebilirler.
* **Akıllı Normalizasyon ve Kriptografik Güvenlik:** Cevaplar büyük/küçük harf ve boşluk duyarsız normalizasyon (`answer.strip().lower()`) sonrasında **PBKDF2-HMAC-SHA256 (600.000 iterasyon)** ile özetlenerek veritabanında saklanır. Yanıtlar hiçbir zaman düz metin olarak tutulmaz.
* **Tek Tıkla Sıfırlama:** Doğru yanıt girildiğinde şifre politikasına uygun yeni şifre atanır ve varsa hesap kilitleri anında kaldırılır.

#### 2. Acil Durum Kurtarma Anahtarı (Master Recovery Key)
* **16 Haneli Kriptografik Anahtar:** Özellikle sistem yöneticisi (Admin) hesabı için karışıklığı önleyen Base32 karakter kümesinden bloklu kurtarma anahtarı (`KASP-XXXX-XXXX-XXXX`) üretilir.
* **Esnek Girdi Desteği:** Anahtar girişi sırasında büyük/küçük harf, tireli veya tiresiz yazımlar otomatik tolere edilir.
* **Çevrimdışı Yönetici Kurtarma:** Hem şifresini hem de güvenlik sorusunu unutan sistem yöneticisi, güvenli bir kasada sakladığı kurtarma anahtarı ile şifresini saniyeler içinde sıfırlayabilir.

#### 3. CLI Acil Durum Sıfırlama Aracı (`--reset-admin`)
* **İşletim Sistemi Seviyesinde Kurtarma:** Makineye doğrudan erişimi olan IT personeli veya sistem yöneticisi için:
  ```bash
  python3 main.py --reset-admin
  ```
* **Sıfır Veri Kaybı:** Hesaplama geçmişi, projeler ve türbin/kompresör veritabanına kesinlikle dokunulmaz. Admin şifresi geçici güvenli değere (`kasp2024`) çekilir, ilk girişte zorunlu şifre değişikliği (`must_change_password=1`) aktif edilir, tüm kilitler kaldırılır ve yeni bir acil kurtarma anahtarı oluşturularak konsola yazdırılır.

#### 4. Arayüz ve Giriş Ekranı Entegrasyonları
* **"Şifremi Unuttum" Sihirbazı:** Giriş ekranına (`LoginDialog`) eklenen `[❓ Şifremi Unuttum]` bağlantısı ile açılan `PasswordRecoveryDialog`, kullanıcıyı adım adım yönlendirir.
* **Standart Kullanıcı Yönlendirmesi:** Güvenlik sorusu tanımlı olmayan standart kullanıcılara doğrudan sistem yöneticisine başvurma rehberliği sunulur.
* **Güvenlik ve Kurtarma Ayarları:** Araçlar menüsüne eklenen `🛡️ Güvenlik ve Kurtarma` penceresi ile kullanıcılar istedikleri an sorularını güncelleyebilir ve yeni kurtarma anahtarı üretebilir.

## 🇺🇸 English Release Notes (v2.4.2)

### 🚀 Offline Multi-Layer Password Recovery & Security Suite

KASP v2.4.2 introduces an enterprise-grade, offline-first multi-layer password recovery architecture tailored for air-gapped industrial environments:

#### 1. Security Question & Answer Recovery
* **Configurable Security Questions:** Users can select from curated templates or define a personalized security question and answer.
* **Case-Insensitive Normalization & PBKDF2 Hashing:** Answers are normalized (`answer.strip().lower()`) and salted using **PBKDF2-HMAC-SHA256 (600,000 rounds)**. Answers are never stored in plain text.
* **Instant Account Unlock:** Verifying the security question validates password policy, updates credentials, and clears active lockouts immediately.

#### 2. Master Recovery Key
* **16-Character High-Entropy Key:** Generates formatted cryptographic recovery keys (`KASP-XXXX-XXXX-XXXX`) using unambiguous characters (excluding easily confused characters like `0, O, 1, I`).
* **Format-Tolerant Verification:** Accepts keys entered in uppercase, lowercase, with or without hyphens and spaces.
* **Air-Gapped Admin Rescue:** Provides administrators a secure, printed or vaulted offline recovery mechanism if passwords and questions are forgotten.

#### 3. CLI Emergency Reset Tool (`--reset-admin`)
* **OS-Level Command-Line Rescue:** System administrators with direct filesystem access can execute:
  ```bash
  python3 main.py --reset-admin
  ```
* **Preserves Application Databases:** Safely resets the admin password to default, forces a new password upon first login (`must_change_password=1`), generates a fresh recovery key, and clears lockout state without altering calculation history or equipment models.

#### 4. UI & Workflow Integrations
* **"Forgot Password" Wizard:** Integrated `[❓ Şifremi Unuttum]` action in `LoginDialog` launching a clean multi-step recovery wizard.
* **Standard User Admin Guidance:** Informs standard accounts without recovery questions to contact the administrator who retains in-app reset privileges.
* **Security Settings Panel:** Added `🛡️ Security & Recovery Settings` dialog under the Tools menu for self-service question management and key generation.
