## 🇹🇷 Türkçe

### 🧠 Akıllı Fallback Mimarisi (Yeni)

- **`kasp/core/fallback.py`** — Yeni modül: `FallbackTracker`, `EosChain`, `SolverChain`
- **EOS Zinciri:** Kullanıcı EOS'u → thermopack → pr → srk → aga8 → ideal gaz
  - Kırık EOS'lar run boyunca işaretlenir, tekrar denenmez
  - `gas_obj` formatı her EOS için otomatik dönüştürülür
  - `raw_props`'a `fallback_layer`, `fallback_from`, `fallback_to`, `fallback_reason` eklendi
- **Çözücü Zinciri:** fd_nr → aj_nr → brent → k-tabanlı formül
  - "auto" modda sıralı fallback (eskiden paralel benchmark)
  - Benchmark verisi ayrıca toplanır (diagnostik için)

### 🐛 Düzeltmeler

- **CCP/DWSIM/AGA8 → PR fallback:** Hata durumunda ideal gaz yerine PR kullanılır
- **CoolProp direkt flash kaldırıldı:** "One stationary point" hatası + 437ms gecikme giderildi
- **`_solve_fallback` H referansı:** 273.15K → 298.15K (standart referans)

### 🖥️ Engineering Dashboard

- **Scrollable yapı:** Tüm paneller kaydırılabilir alan içinde

## 🇬🇧 English

### 🧠 Smart Fallback Architecture (New)

- **`kasp/core/fallback.py`** — New module: `FallbackTracker`, `EosChain`, `SolverChain`
- **EOS Chain:** user EOS → thermopack → pr → srk → aga8 → ideal gas
  - Broken EOS skipped for entire run
  - `gas_obj` format auto-converted per EOS
- **Solver Chain:** fd_nr → aj_nr → brent → k-based formula
  - Sequential fallback in "auto" mode
  - Benchmark data collected alongside

### 🐛 Fixes

- **CCP/DWSIM/AGA8 → PR fallback:** PR used instead of ideal gas on error
- **CoolProp direct flash removed:** Eliminates "one stationary point" error + 437ms delay
- **`_solve_fallback` H reference:** 273.15K → 298.15K

### 🖥️ Engineering Dashboard

- **Scrollable:** All panels in scroll area
- **Expanded EOS Shootout (10 cols):** Status, Fallback Layer, Fallback Chain
- **🔄 Fallback Chain Log panel**
