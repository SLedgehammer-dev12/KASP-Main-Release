# KASP v1.6.2 — Sürüm Notları / Release Notes

## 🇹🇷 Türkçe

### Yeni Özellikler & İyileştirmeler
- **ISO 6976:2016 LHV/HHV Arayüz Desteği** — Arayüzdeki LHV/HHV Kaynağı seçim kutusuna `"ISO 6976 Standardı (Molar / Z Düzeltmeli)"` seçeneği eklendi. Böylece, harici `thermo` kütüphanesi yüklü olmasa bile ISO 6976 standardı molar ve gerçek gaz sıkıştırılabilirlik faktörü (Z) düzeltmeli hesaplama yöntemi arayüz üzerinden doğrudan seçilebilir ve çalıştırılabilir.
- **Akıllı Arayüz Kısıtlamaları** — Harici `thermo` veritabanı kütüphanesi bulunamadığında LHV/HHV kaynak açılır menüsünün tamamen devre dışı kalması yerine, sadece bulunamayan `"Thermo Veritabanı"` seçeneği devre dışı bırakılır; `"ISO 6976 Standardı"` ve `"KASP Sabitleri"` seçenekleri tamamen erişilebilir durumda kalır.
- **Dinamik macOS Paketi Hacim Adı** — macOS için oluşturulan `.dmg` yükleyici paketinin hacim adı dinamik hale getirilerek sistem güncellemeleri ve dağıtımları kolaylaştırıldı.

### Düzeltmeler & Altyapı
- PyInstaller spec yapılandırmaları ve derleme betikleri v1.6.2 standartlarına göre güncellendi.
- GitHub Actions CI/CD otomatik dağıtım akışındaki macOS paketleme adımı dinamikleştirildi.
- Test kapsamı güncellenen arayüz bileşenleri ve versiyon tanımları ile %100 uyumlu hale getirildi.

## 🇬🇧 English

### New Features & Improvements
- **ISO 6976:2016 LHV/HHV UI Integration** — Exposed `"ISO 6976 Standardı (Molar / Z Düzeltmeli)"` in the LHV/HHV Source dropdown widget in both Design and Performance tabs. Users can now run real-gas compressibility factor (Z) corrected calculations directly from the UI even when the external `thermo` database library is not installed.
- **Smart UI Restraints** — Instead of fully disabling the LHV/HHV dropdown when the external `thermo` library is missing, only the `"Thermo Database"` option is disabled, leaving the `"ISO 6976 Standard"` and `"KASP Constants"` options fully selectable.
- **Dynamic macOS Volume Naming** — Generalised the volume naming in macOS DMG creation script, improving portability and automation.

### Fixes & Infrastructure
- PyInstaller spec profiles and compilation batch/shell scripts updated for v1.6.2.
- CI/CD workflow release actions automated with dynamic macOS packaging steps.
- Test coverage synced with modified UI items and release definitions.
