## 🇹🇷 Türkçe Sürüm Notları (v2.6.3)

### 🔐 Masaüstü Oturum Güvenliği ve Giriş Akışı Düzeltmeleri

Bu sürüm, masaüstü uygulamasında giriş deneyimini güvenli ve kalıcı hale getirir;
tekrarlayan zorunlu şifre değişikliği döngüsünü ortadan kaldırır.

#### 1. "Beni hatırla" ile kalıcı oturum
* Giriş ekranına **“Beni hatırla (30 gün)”** onay kutusu eklendi.
* Şifre diskte **saklanmaz**. Bunun yerine 30 gün geçerli, rastgele bir oturum
  jetonu üretilir; veritabanında yalnızca **SHA-256 özeti** tutulur.
* Ham jeton, uygulama veri dizininde yalnızca sahibinin okuyabildiği
  **0600** izinli `kasp_remember.json` dosyasında saklanır.
* Jeton her otomatik girişte **döndürülür (rotation)**; eski jeton tekrar
  kullanılamaz.
* Kurtarma anahtarı, yönetici şifre sıfırlaması, kullanıcı şifre değişimi ve
  **Çıkış Yap** işlemleri tüm jetonları anında iptal eder.
* `must_change_password=1` iken otomatik giriş reddedilir; kullanıcı şifresini
  değiştirmeye yönlendirilir.
* Kutu boş bırakılırsa kayıtlı oturum silinir.

#### 2. Tekrarlayan "Şifreniz bir admin tarafından sıfırlandı" uyarısı giderildi
* **Kök neden:** Uygulama her açılışta `ensure_default_admin_must_change_password()`
  çağırıyor ve `admin.must_change_password` bayrağını koşulsuz olarak `1`'e
  geri alıyordu. Bu nedenle şifre bir kez değiştirilse bile her girişte uyarı ve
  zorunlu şifre değişikliği ekranı açılıyordu.
* Başlangıç mantığı `ensure_initial_admin(db)` olarak yeniden düzenlendi.
  Yalnızca **Users tablosu boşsa** tek seferlik admin parolası üretilir; mevcut
  kurulumlara ve şifre değişikliği durumuna dokunulmaz.
* Zorunlu şifre değişikliği artık sadece iki durumda uygulanır:
  1. İlk kurulum,
  2. Yönetici tarafından şifre sıfırlaması.
* Hatalı yeniden zorlama metodu veritabanı katmanından kaldırıldı.

#### 3. Doğrulama ve Kalite Kapıları

  açıldı; `Zorunlu Şifre Değişikliği` diyaloğu tetiklenmedi.

#### 4. v2.6.3 Hattındaki Diğer Özellikler
* İstasyon borulama sınır mimarisi, PTC-10 / Shootout arayüz kaplini ve
  proje-rapor kalıcılığı.

## 🇺🇸 English Release Notes (v2.6.3)

> **Re-release:** macOS and Windows packages were rebuilt for the v2.6.3 line
> with the session-security and mandatory-password fixes below. Version number
> is unchanged: **v2.6.3**.

### 🔐 Desktop Session Security and Login Flow Fixes

#### 1. Persistent session with "Remember me"
* Added a **“Remember me (30 days)”** checkbox to the desktop login dialog.
* Passwords are **never stored on disk**. A random, 30-day session token is
  issued instead; only its **SHA-256 digest** is stored in the database.
* The raw token lives in `kasp_remember.json` inside the application data
  directory with **0600** permissions (owner read/write only).
* The token is **rotated** on every automatic login; the previous token becomes
  invalid.
* Recovery-key use, administrator password reset, user password change and
  **Log out** revoke all tokens immediately.
* Automatic login is rejected while `must_change_password=1`.
* Clearing the checkbox deletes the saved session.

#### 2. Repeating "Your password was reset by an admin" warning fixed
* **Root cause:** On every startup the application called
  `ensure_default_admin_must_change_password()`, which unconditionally set
  `admin.must_change_password` back to `1`. Even after changing the password,
  every login showed the warning and the forced password-change dialog.
* Startup logic was refactored into `ensure_initial_admin(db)`. A one-time admin
  password is generated **only when the Users table is empty**; existing
  installations and password changes are left untouched.
* Forced password change now applies only to:
  1. First install,
  2. Administrator-initiated password reset.
* The faulty re-arming helper was removed from the database layer.

#### 3. Verification and Quality Gates
* New tests: `test_remember_me.py` (10) and `test_admin_must_change.py` (4) —
  token hashing/permissions/expiry/rotation, automatic login, and restart
  behaviour after a password change.
* Affected security, user-management and API suites: **79 tests**.
* Full suite: **660 passed, 12 skipped, 0 failed**.
* `kasp_verify.py doctor`: **ok**.
* Real application check: the rebuilt binary went straight to the main window
  after login; no forced password-change dialog was triggered.

#### 4. Other v2.6.3 Scope
* Station piping boundary architecture, PTC-10 / Shootout interface coupling,
  project/report persistence.
* Real-gas EOS improvements, Schultz/Mallory polytropic integration, turbine and
  aerodynamic accuracy hardening.
* Web platform: dynamic gas component selector, turbine fuel transparency,
  3D digital twin and equipment teardown views.
* Web Edition packaging and automatic update check.
