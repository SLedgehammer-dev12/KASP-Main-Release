# KASP v2.6.0 Sürüm Notları / Release Notes

## 🇹🇷 Türkçe Sürüm Notları (v2.6.0)

### 🛠️ Kritik Termodinamik Düzeltmeler, Web Kimlik Doğrulama ve Dayanıklılık

KASP v2.6.0; hesaplama doğruluğunu, güvenliği ve operasyonel sağlamlığı iyileştiren düzeltmeler ile yeni teşhis araçlarını bir araya getirir.

#### 1. Kritik Doğruluk Düzeltmeleri
* **AGA8-DC92 Birim Hatası (Kritik):** pyaga8'e basınç artık **kPa** (önceden MPa) veriliyor; yoğunluk **mol/L**'den doğru şekilde dönüştürülüyor (önceden mol/cm³ varsayılıyordu). Bu düzeltme, tüm gerçekçi basınçlarda sessizce ideal-gaz sonucu (Z≈1, hatalı Cp/Cv ve ses hızı) üreten hatayı giderir. Saf metan 5 MPa / 300 K için doğru değerler: Z≈0.9195, ρ≈34.97 kg/m³.
* **Updater SHA256 Eşlemesi:** Release gövdesindeki hash'ler artık doğru varlığa bağlanıyor; şüpheli durumda güvenli tarafta kalıp (fail-closed) indirmeyi reddediyor.

#### 2. Güvenlik ve Operasyonel Hijyen
* **Web Arayüzü Kimlik Doğrulaması:** Tarayıcı arayüzü, korumalı `/api/calculate/*` uç noktalarına `Authorization: Bearer <token>` gönderiyor; kalıcı token alanı eklendi ve `401/403` durumu net biçimde gösteriliyor.
* **Release Build Metadata:** Var olmayan `build_release_v2.5.1.bat/.sh` referansları kaldırıldı; `build_release.py` gerçek spec dosyalarıyla çalışan `pyinstaller` komutlarını yazdırıyor. Referans verilen dosyaların varlığını doğrulayan drift testi eklendi.
* **Atomik Güncelleme İndirmesi:** İndirme önce `.part` dosyasına yazılıp SHA256 doğrulandıktan sonra atomik olarak yeniden adlandırılıyor.

#### 3. Girdi Güvenliği ve Dayanıklılık
* Politropik verim normalizasyonu (kesir/yüzde), mol fraksiyonu/yüzde kompozisyon desteği ve toleranslı birim takma adları.
* Türbin seçimi sıfır/negatif/sonsuz güç ve aralık dışı ortam koşullarına karşı korunuyor; katalog önbelleği iş parçacığı güvenli hale getirildi.
* Tasarım/performans sonuç panelleri, PDF raporları, grafikler ve proje kaydı eksik/None/NaN alanlara karşı dayanıklı.

#### 4. Yeni Özellikler
* **Karşılaştırmalı Benchmark çözücü modu** (otomatik akıllı zincirden ayrı, teşhis amaçlı).
* **Metot Shootout detay paneli** — kademe yakınsaması, referans sapmaları ve ham özellikler.
* **Kademe bazlı PDF raporu** ve **Petrobras ccp adaptörü**.

#### 5. Test
* Tam test takımı: **405 geçti, 12 atlandı, 0 hata**.

## 🇺🇸 English Release Notes (v2.6.0)

### 🛠️ Critical Thermodynamic Fixes, Web Auth & Resilience

KASP v2.6.0 combines correctness, security and robustness fixes with new diagnostic tools.

#### 1. Critical Correctness Fixes
* **AGA8-DC92 Unit Fix (Critical):** pyaga8 now receives pressure in **kPa** (was MPa) and molar density is converted from **mol/L** (was treated as mol/cm³). This removes a silent ideal-gas behaviour (Z≈1, wrong Cp/Cv and sound speed) at all realistic pressures. Reference for pure methane at 5 MPa / 300 K: Z≈0.9195, ρ≈34.97 kg/m³.
* **Updater SHA256 Binding:** release-body hashes are bound to the correct asset, failing closed when ambiguous.

#### 2. Security & Operational Hygiene
* **Web UI Authentication:** the browser UI sends `Authorization: Bearer <token>` to protected `/api/calculate/*` endpoints, with a persisted token field and a clear `401/403` state.
* **Release Build Metadata:** removed non-existent `build_release_v2.5.1.bat/.sh` references; `build_release.py` prints runnable `pyinstaller` commands. A drift test asserts referenced artifacts exist.
* **Atomic Update Download:** writes to a `.part` file and renames atomically after SHA256 verification.

#### 3. Input Safety & Resilience
* Polytropic-efficiency normalization (fraction/percentage), mole-fraction/percentage composition support and tolerant unit aliases.
* Turbine selection guards for zero/negative/non-finite power and out-of-range ambient conditions; thread-safe catalog caching.
* Design/performance result presenters, PDF reports, graphs and project serialization tolerate missing/None/NaN fields.

#### 4. New Features
* **Benchmark solver mode** (diagnostic, separate from the automatic smart chain).
* **Method shootout detail panel** — stage convergence, reference deltas and raw properties.
* **Stage-by-stage PDF breakdown** and a **Petrobras ccp adapter**.

#### 5. Tests
* Full suite: **405 passed, 12 skipped, 0 failed**.
