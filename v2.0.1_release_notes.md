# KASP v2.0.1 — Hotfix: Thermopack Bundle & Log Spam

## 🇹🇷 Türkçe

### 🐛 Bug Fixes

#### 🔧 Thermopack PyInstaller Bundle Düzeltmesi
- `thermopack` kütüphanesinin binary dosyaları (`libthermopack.dynlib`, `.dylibs/*`) PyInstaller build'ine dahil edilmediği için "No such file or directory" hatası alınıyordu
- macOS ve Windows `.spec` dosyalarına `collect_data_files('thermopack')` ve `collect_submodules('thermopack')` eklendi
- Artık Thermopack EOS, PyInstaller ile build edilmiş uygulamada da doğru çalışıyor

#### 📝 Fallback Warning Log Spam Bastırma
- EOS hatası durumunda her çağrıda WARNING basılıyordu (hesaplama başına 60+ kez)
- Rate-limit eklendi: Her EOS için run başına sadece **1 kez** WARNING, sonrakiler DEBUG seviyesinde loglanır
- `begin_run_tracking()` ile her hesaplama başlangıcında sayaç sıfırlanır

---

## 🇬🇧 English

### 🐛 Bug Fixes

#### 🔧 Thermopack PyInstaller Bundle Fix
- Thermopack binary files (`libthermopack.dynlib`, `.dylibs/*`) were not included in PyInstaller builds, causing "No such file or directory" errors
- Added `collect_data_files('thermopack')` and `collect_submodules('thermopack')` to both macOS and Windows `.spec` files
- Thermopack EOS now works correctly in PyInstaller-bundled applications

#### 📝 Fallback Warning Log Spam Suppression
- Every failed EOS call produced a WARNING log (60+ per calculation)
- Added rate-limiting: Only **1 WARNING** per EOS per run; subsequent failures logged at DEBUG level
- Counter resets on `begin_run_tracking()` at each calculation start
