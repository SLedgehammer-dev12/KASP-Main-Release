## 🇹🇷 Türkçe

### 🎯 Ana Yenilikler

**Dinamik Responsive Arayüz (DPI-Aware)**
- Tüm sabit piksel boyutları (%30+) DPI ve ekran çözünürlüğüne duyarlı hale getirildi
- Yeni `kasp/ui/responsive.py` altyapısı: `scaled_px()`, `scaled_font_pt()`, `dialog_size()`, `get_screen_category()`, ekran breakpoint sistemi (≤1366 / ≤1920 / ≤2560 / >2560)
- Küçük ekranlar için (1366×768) otomatik kompakt mod (`compact_padding`, `compact_spacing`, `_compact_left_panel()`)
- Yüksek DPI (144/200/250+) desteği — tüm fontlar, butonlar, padding'ler otomatik ölçeklenir
- UI Scale kullanıcı tercihi (config: `app.ui_scale` — 0.85 / 1.0 / 1.25)

**QSplitter — Sürüklenebilir Panel Bölücüler**
- Tasarım sekmesi: QHBoxLayout → **QSplitter** (sol panel / sağ panel sürüklenebilir)
- Performans sekmesi: QHBoxLayout → **QSplitter** (giriş paneli / sonuç paneli sürüklenebilir)
- Splitter pozisyonları QSettings ile kaydedilir, program tekrar açıldığında geri yüklenir
- Sol/sağ panel `setChildrenCollapsible(False)` — paneller tamamen kapanamaz

**QScrollArea Wrapper'ları**
- Tasarım sağ paneli → QScrollArea içine alındı (sonuç sekmeleri taşma koruması)
- Performans giriş paneli → QScrollArea wrapper
- Performans sonuç paneli → QScrollArea wrapper
- Log sekmesi zaten QTextEdit scroll ile korunuyor

**Diyalog Boyutları — Ekran Yüzdesi**
- Tüm diyaloglar sabit piksel yerine ekran yüzdesi ile boyutlandırılıyor
- `CompressorEditDialog`: %35 × %45, `TurbineDetailDialog`: %40 × %35, `ChangelogDialog`/`UpdateDialog`: %50 × %38
- `LibraryManagerWindow`: %75 × %60 + maximize butonu

**Tema CSS — DPI-Aware**
- 26 CSS değeri (padding, font-size, min-width, min-height) dinamik DPI hesaplamasına bağlandı
- Buton padding'leri, resultLabel font boyutu, scrollbar genişliği, sekme padding'i — hepsi `_px()`/`_pt()` responsive

## 🇬🇧 English

### 🎯 Key Features

**Dynamic Responsive UI (DPI-Aware)**
- All hardcoded pixel dimensions (30%+) made DPI and screen-resolution aware
- New `kasp/ui/responsive.py` foundation: `scaled_px()`, `scaled_font_pt()`, `dialog_size()`, `get_screen_category()`, screen breakpoint system (≤1366 / ≤1920 / ≤2560 / >2560)
- Automatic compact mode for small screens (1366×768) — `compact_padding`, `compact_spacing`
- High DPI support (144/200/250+) — all fonts, buttons, padding auto-scale
- UI Scale user preference (config: `app.ui_scale` — 0.85 / 1.0 / 1.25)

**QSplitter — Draggable Panel Dividers**
- Design tab: QHBoxLayout → **QSplitter** (left panel / right panel draggable)
- Performance tab: QHBoxLayout → **QSplitter** (input / result panels draggable)
- Splitter positions saved via QSettings, restored on next launch
- `setChildrenCollapsible(False)` — panels cannot fully collapse

**QScrollArea Wrappers**
- Design right panel → QScrollArea wrapper (result tabs overflow protection)
- Performance input panel → QScrollArea wrapper
- Performance result panel → QScrollArea wrapper

**Dialog Sizing — Screen Percentage**
- All dialogs sized by screen percentage instead of fixed pixels
- `CompressorEditDialog`: 35% × 45%, `TurbineDetailDialog`: 40% × 35%, `ChangelogDialog`/`UpdateDialog`: 50% × 38%
- `LibraryManagerWindow`: 75% × 60% + maximize button

**Theme CSS — DPI-Aware**
- 26 CSS values (padding, font-size, min-width, min-height) bound to dynamic DPI computation
- Button padding, resultLabel font size, scrollbar width, tab padding — all `_px()`/`_pt()` responsive
