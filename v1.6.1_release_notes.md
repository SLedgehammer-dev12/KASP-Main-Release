# KASP v1.6.1 — Sürüm Notları / Release Notes

## 🇹🇷 Türkçe

### Yeni Özellikler
- **Giriş Güvenliği** — PBKDF2-SHA256 brute-force korumalı login dialog. Varsayılan şifre `123456`, 5/10/15 deneme kilitleme.
- **10 Yeni Türbin** — GE LM2500Xpress, Siemens SGT-900, Solar Titan 350 ve daha fazlası eklendi (toplam 156 türbin).
- **Boyutsuz Katsayılar (Tasarım Sekmesi)** — Tahmini ψ, φ, Re, Ma değerleri otomatik hesaplanır. Kullanıcı girdisi gerekmez.
- **ASME PTC 10 Benzerlik (Performans Sekmesi)** — Gerçek boyutsuz katsayılar + çark geometrisi ile ASME PTC 10 benzerlik kontrolü. D (çap), b (kanat genişliği), RPM girildiğinde aktif olur.
- **Tam Responsive Arayüz** — DPI-aware font/css, ekran kırılım noktası sistemi (XS→XL), Retina/4K desteği, pencere boyutu oturumlar arası hatırlama.

### Düzeltmeler
- CoolProp "One stationary point" hatası AGA8 fallback ile düzeltildi.
- Log seviyesi başlangıç mesajı artık dinamik versiyon gösteriyor.

## 🇬🇧 English

### New Features
- **Login Security** — PBKDF2-SHA256 brute-force protected login dialog. Default password `123456`, 5/10/15 attempt lockout.
- **10 New Turbines** — GE LM2500Xpress, Siemens SGT-900, Solar Titan 350 and more added (156 total turbines).
- **Dimensionless Coefficients (Design Tab)** — Estimated ψ, φ, Re, Ma values auto-calculated. No user input required.
- **ASME PTC 10 Similarity (Performance Tab)** — Actual dimensionless coefficients + impeller geometry for ASME PTC 10 similarity check. Active when D (diameter), b (blade width), RPM are provided.
- **Full Responsive UI** — DPI-aware font/css, screen breakpoint system (XS→XL), Retina/4K support, window geometry persistence between sessions.

### Fixes
- CoolProp "One stationary point" error handled via AGA8 fallback solver.
- Startup log message now displays dynamic version number.
