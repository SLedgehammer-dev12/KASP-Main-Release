# KASP v2.5.0 Sürüm Notları / Release Notes

## 🇹🇷 Türkçe Sürüm Notları (v2.5.0)

### 🚀 Büyük Termodinamik Motor Revizyonu, API 617 / ASME PTC 10 Uyumluluğu ve Güvenlik Güçlendirmesi

KASP v2.5.0 sürümü, termodinamik motorun mühendislik hassasiyetini artıran, endüstri standardı doğrulama kurallarını (API 617, ASME PTC 10) entegre eden, arayüz ergonomisini ve operasyonel güvenliği en üst seviyeye taşıyan kapsamlı bir ana sürümdür:

#### 1. Termodinamik Motor ve Fiziksel Doğruluk
* **ASME PTC 10 & API 617 Entegrasyonu:** Politropik üs, Schultz $f_t$ sıkıştırılabilirlik düzeltmesi ve gerçek gaz yolu entegrasyonu standartlara tam uyumlu hale getirildi. Motor seçiminde API 617'nin öngördüğü %4 sürücü toleransı merkezi olarak yönetildi.
* **Fiziksel Verim Sınırlandırması (Efficiency Clamping):** %100'ün üzerinde (%120 vb.) veya negatif çıkan fizik-dışı izentropik ve politropik verimler `[0.0, 1.0]` aralığına kelepçelendi; sahada hatalı kabul kararlarını önlemek amacıyla açık mühendislik uyarıları eklendi.
* **VLE Faz Zarfı ve Knockout Drum Analizi:** Sıkıştırma hatlarında yoğuşma riski ($V_F < 1.0$) tespiti, minimum Gibbs serbest enerjisi ve fugasite kontrolleriyle güçlendirildi.
* **Gerçekçi Surge Margin & Stonewall Hesabı:** API 617'ye göre hatalı referanslardan kaynaklanan aşırı yüksek (örn. %3500+) surge marjı anomalisi giderildi, fiziksel marj hesaplaması sağlandı.
* **İnert Gaz Yakıt Debisi Düzeltmesi:** LHV <= 0 olan inert yakıtlar (N₂, CO₂ vb.) için sistemin fosil yakıt varsayımıyla yakıt tüketimi hesaplaması engellendi, 0 kg/h değeriyle fiziksel gerçekliğe uyarlandı.
* **Birim Dönüşüm Güvenceleri:** Ara soğutucu ve giriş sıcaklıklarında Kelvin, Celsius ve Fahrenheit birim dönüşümleri netleştirildi; mutlak/gauge basınç sınır kontrolleri sıkılaştırıldı.
* **Thread-Safe Çözücü Mimarisi:** Çok çekirdekli ortamlarda CoolProp `AbstractState` nesneleri kilitleme mekanizmasıyla korunarak eşzamanlı hesaplamalarda veri bozulması önlendi.

#### 2. Güvenlik, Veri Tabanı ve Operasyonel Hijyen
* **Kullanıcı Veritabanı İzolasyonu:** `kasp_database.db` Git takibinden çıkarıldı, `.gitignore`'a `*.db` kuralı eklendi ve PyInstaller derleme spesifikasyonlarından kaldırılarak son kullanıcı verileri ile yönetici parolalarının dağıtım paketlerine sızması engellendi.
* **Varsayılan Parola Değişiklik Güvencesi:** PBKDF2 rastgele salt'lı şifreleme kontrolü onarılarak, varsayılan parola ile çalışan sistemlerde zorunlu şifre değişikliği (`must_change_password=1`) zorunlu kılındı.
* **SQLite WAL & Eşzamanlılık Desteği:** Veritabanı kilitlenmelerine karşı `PRAGMA busy_timeout = 5000` ve `PRAGMA journal_mode = WAL` mimarisine geçildi.

#### 3. Kullanıcı Deneyimi, UI ve Ergonomi
* **Eski Sonuçların Otomatik Temizlenmesi:** Hesaplama hatası, performans analizi hatası veya "Yeni Proje" açılışında önceki analizin ekranda asılı kalması engellendi; sonuç panelleri ve grafikler temizlenerek hatalı raporlama riski ortadan kaldırıldı.
* **Mojibake ve Karakter Kodlama Düzeltmeleri:** Kritik hata ve uyarı mesajlarındaki bozuk UTF-8 karakterler giderildi.
* **Raporlama ve Fallback Şeffaflığı:** PDF raporlarında çözücü fallback gerçekleştiğinde (`İstenen EOS -> Efektif EOS`) şeffaf bir şekilde belgelendi; DejaVu Sans Türkçe karakter desteği optimize edildi.
* **Performans Girişlerinin Korunması:** Türbin verimi ve yakıt debisi modları arasında geçiş yapıldığında kullanıcının girdiği verilerin kaybolması önlendi.
* **Klavye Kısayolları:** Hesaplama başlatmak için `F5` / `Ctrl+R` kısayolu tanımlandı.

#### 4. Çapraz Platform Desteği
* Windows, Linux (Ubuntu) ve macOS üzerinde uçtan uca GitHub Actions CI matrisi **%100 başarılı** olarak doğrulandı.
* DWSIM .NET kütüphane bağımlılığı platforma özgü optimize edildi; Linux ve macOS üzerinde temiz ve kararlı fallback davranışı sağlandı.

## 🇺🇸 English Release Notes (v2.5.0)

### 🚀 Major Thermodynamic Engine Overhaul, ASME PTC 10 / API 617 Compliance & Security Hardening

KASP v2.5.0 represents a major milestone focusing on thermodynamic precision, industrial compliance with ASME PTC 10 & API 617, UI ergonomics, and operational security:

#### 1. Thermodynamic Accuracy & Core Physics
* **ASME PTC 10 & API 617 Compliance:** Fully standardized polytropic exponent evaluation, Schultz compressibility factor ($f_t$) integration, real-gas path integrals, and gas power balance verification. Centralized the API 617 4% driver margin across selection and sizing routines.
* **Physical Efficiency Clamping & Guardrails:** Clamped physically impossible isentropic and polytropic efficiencies (>100% or negative) to `[0.0, 1.0]` with explicit engineering warning logs to prevent erroneous field acceptance.
* **VLE Phase Envelope & Knockout Drum Analysis:** Enhanced condensation detection ($V_F < 1.0$) and minimum Gibbs free energy / fugacity phase stability checks.
* **Accurate Surge Margin & Stonewall Calculation:** Eliminated anomalous surge margin values (e.g. 3500%+) caused by incorrect reference flows, enforcing robust aerodynamic boundaries.
* **Inert Gas Fuel Consumption Fix:** Prevented false fuel consumption calculation for non-combustible gases (N₂, CO₂, etc.) when LHV <= 0.
* **Unit Conversion & Pressure Bounds:** Hardened temperature conversions across Kelvin, Celsius, and Fahrenheit for intercoolers and stage inlets; strictly guarded absolute and gauge pressures.
* **Thread-Safe Thermodynamic Solvers:** Guarded CoolProp `AbstractState` instances with concurrency locks to prevent race conditions during parallel evaluations.

#### 2. Security & Database Hygiene
* **Clean Artifact Packaging:** Untracked `kasp_database.db` from version control, added `*.db` to `.gitignore`, and purged production databases from PyInstaller specs to ensure customer data and admin hashes never ship in release binaries.
* **Mandatory Password Reset Enforcement:** Fixed PBKDF2 verification for the initial admin credential, ensuring `must_change_password=1` triggers reliably.
* **SQLite Concurrency & WAL Mode:** Activated `PRAGMA busy_timeout = 5000` and `PRAGMA journal_mode = WAL` to prevent database locks in concurrent workflows.

#### 3. User Experience & Reporting
* **Stale State Elimination:** Automatically clears residual results, summary cards, and stage tables upon calculation failure, performance error, or creating a new project.
* **UTF-8 Mojibake Elimination:** Cleaned up malformed Turkish character sequences in critical error and confirmation dialogs.
* **Transparent EOS Fallback Reporting:** Clear PDF audit trail displaying `Requested EOS -> Effective EOS` whenever numerical fallback occurs.
* **Input State Preservation:** Retains user-entered values in the performance evaluation tab when toggling between efficiency and fuel rate driver modes.
* **Keyboard Shortcuts:** Added `F5` / `Ctrl+R` shortcut for instant calculation triggers.

#### 4. Cross-Platform & CI Validation
* End-to-end verified across Windows, Linux (Ubuntu), and macOS with **100% passing test matrix** on GitHub Actions.
* DWSIM .NET integration isolated to Windows environments with graceful, seamless fallback on Linux and macOS.
