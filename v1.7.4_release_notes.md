## 🇹🇷 Türkçe

### 🎯 Ana Yenilikler

#### 🧪 DWSIM Standalone Thermodynamics Engine (YENİ)
- **DWSIM .NET termodinamik motoru** tam entegrasyonla eklendi
- 16+ EOS modeli: Peng-Robinson, PRSV2, SRK, Lee-Kesler-Plöcker, PC-SAFT, GERG-2008
- **Steam Tables (IAPWS-IF97)** — su buharı sıkıştırma simülasyonları için
- **NRTL / UNIQUAC** — nemli gaz (wet gas) ve polar karışımlar için aktivite katsayısı modelleri
- Otomatik SteamTables algılama: su oranı > %5 ise PR yerine IAPWS-IF97 kullanılır
- **Viskozite ve termal iletkenlik** özellikleri DWSIM üzerinden hesaplanır
- pythonnet yoksa veya DLL bulunamazsa DWSIM seçeneği otomatik olarak devre dışı kalır (çökme yok)

#### 👥 Gelişmiş Kullanıcı Yönetimi (YENİ)
- **Çoklu kullanıcı desteği**: her kullanıcı kendi kullanıcı adı ve şifresiyle giriş yapar
- **4 rol seviyesi**: Admin, Engineer, User, Viewer
- **Admin paneli**: Kullanıcı ekle/düzenle/sil, şifre sıfırla, aktif/pasif yap
- **Yetki kontrolü**: Rol bazlı menü ve özellik erişimi (admin paneli sadece admin'e görünür)
- **Oturum yönetimi**: Giriş/çıkış, son giriş takibi
- PBKDF2-SHA256 (600K iterasyon) ile güvenli şifre saklama
- Varsayılan admin: `admin / kasp2024` (ilk girişte değiştirilmesi önerilir)

#### 🔧 3-Katmanlı Mimari Düzeltmeleri
- **Metot 4 (Direct H-S) çözücü seçim hatası düzeltildi**: Kullanıcının seçtiği State Solver (AJ-NR/FD-NR/Brent) artık Metot 4 tarafından da kullanılıyor
- **BRENT kök bulucu güvenlik bandı**: Kök braketlenemediğinde bisection fallback stratejisi eklendi
- **ThermoHandbook teması**: El kitabı artık uygulama temasına (Açık/Koyu/Mühendislik) dinamik uyum sağlıyor
- **DWSIM UI seçeneği**: pythonnet yoksa dropdown'da pasif hale getirildi

#### 📚 Yeni Test Suite
- `test_dwsim_integration.py` — DWSIM EOS, SteamTables, viskozite testleri
- `test_user_manager.py` — 21 test: CRUD, auth, şifre yönetimi, rol kontrolleri
- `test_security_session.py` — 17 test: Session, PermissionManager, yetki kontrolleri
- Toplam test sayısı: **113 test** (72 mevcut + 41 yeni)

## 🇬🇧 English

### 🎯 Key Features

#### 🧪 DWSIM Standalone Thermodynamics Engine (NEW)
- **DWSIM .NET thermodynamics engine** fully integrated as 7th EOS option
- 16+ EOS models available: Peng-Robinson, PRSV2, SRK, Lee-Kesler-Plöcker, PC-SAFT, GERG-2008
- **Steam Tables (IAPWS-IF97)** — for steam compression simulation
- **NRTL / UNIQUAC** — activity coefficient models for wet gas and polar mixtures
- Auto SteamTables detection: water fraction > 5% triggers IAPWS-IF97 instead of PR
- **Viscosity and thermal conductivity** calculated via DWSIM
- Graceful fallback: DWSIM option auto-disables if pythonnet/DLL is missing (no crash)

#### 👥 Advanced User Management (NEW)
- **Multi-user support**: each user logs in with their own credentials
- **4 role levels**: Admin, Engineer, User, Viewer
- **Admin panel**: Add/edit/delete users, reset passwords, toggle active/inactive
- **Permission control**: Role-based menu and feature access (admin panel visible only to admins)
- **Session management**: Login/logout, last-login tracking
- PBKDF2-SHA256 (600K iterations) secure password hashing
- Default admin: `admin / kasp2024` (recommended to change on first login)

#### 🔧 3-Layer Architecture Fixes
- **Method 4 solver selection bug fixed**: User-selected State Solver (AJ-NR/FD-NR/Brent) now properly used by Method 4
- **BRENT root-finder safety net**: Bisection fallback strategy when root bracket fails
- **ThermoHandbook theme**: Handbook now dynamically adapts to app theme (Light/Dark/Engineering)
- **DWSIM UI option**: Disabled in dropdown when pythonnet is not installed

#### 📚 New Test Suite
- `test_dwsim_integration.py` — DWSIM EOS, SteamTables, viscosity tests
- `test_user_manager.py` — 21 tests: CRUD, auth, password management, role checks
- `test_security_session.py` — 17 tests: Session, PermissionManager, permission checks

## 🔄 Installation

### Windows
1. Download `KASP v1.7.4.exe`
2. Double-click to run (no installation required)
3. **DWSIM support**: .NET Framework 4.x is pre-installed on Windows 10/11. The DWSIM EOS option works out of the box.

### macOS
1. Download `KASP v1.7.4.dmg`
2. Drag `KASP v1.7.4.app` to Applications
3. **First launch:** Right-click → Open → Open (Gatekeeper bypass)
4. **DWSIM support**: Requires Mono or .NET SDK installed separately. Without it, DWSIM option is disabled; all other 6 EOS models work normally.
