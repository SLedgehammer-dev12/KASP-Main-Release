## 🇬🇧 English

### 🎯 Major Features

#### 🧪 DWSIM Standalone Thermodynamics Engine (7th EOS)
- 16+ EOS models: Peng-Robinson, PRSV2, SRK, Lee-Kesler-Plöcker, PC-SAFT, GERG-2008
- **Steam Tables (IAPWS-IF97)** — auto-switches when water > 5%
- **NRTL / UNIQUAC activity coefficient models** — for wet gas and polar mixtures
- **Viscosity and thermal conductivity** calculation
- Graceful fallback when pythonnet is missing — no crash, other 6 EOS work normally
- DWSIM DLL bundled in Windows release

#### 👥 Advanced User Management
- **Multi-user login**: Username + password with individual sessions
- **4 roles**: Admin, Engineer, User, Viewer — role-based menu/feature access
- **Admin panel**: Add/edit/delete users, reset passwords, toggle active/inactive, assign roles
- **Session management**: Login/logout, last-login tracking, forced password change
- **PBKDF2-SHA256** (600K iterations) secure password hashing
- Default: `admin / kasp2024`

#### 🛠️ Engineering Mode (Admin Only)
- Toggle via Admin Panel checkbox
- **Calculation Trace Tree**: Per-stage/iteration T, P, Z, k values in expandable tree
- **Performance Metrics**: Cache hit rate, EOS call count, calculation time
- **Thermo Health**: Z-factor anomalies, phase warnings (color-coded)
- **DEBUG log level**: 36 hidden debug messages become visible in UI
- **EOS Shootout**: Compare all 7 EOS engines on identical inputs
- **Method Shootout**: Compare all 4 sizing methods on identical inputs
- **Cache Performance graph**: Now selectable from graph dropdown
- **Log tab**: Visible only to admin users
- **CSV export**: Export trace data for external analysis

#### 🔧 3-Layer Architecture Fixes
- **Method 4 solver bypass fixed**: User-selected State Solver now properly dispatched in Direct H-S
- **BRENT bracket safety net**: Bisection fallback when root bracket fails
- **ThermoHandbook theme**: SVG diagram dynamically adapts to app theme
- **Level-aware log filter**: Hierarchical filtering instead of substring matching

#### 📚 Test Suite
- **132 tests** (83% increase from 72)
- 7 new test files covering DWSIM, user management, security, engineering mode
- 0 regressions

## 🔄 Installation

### Windows
1. Download `KASP v2.0.0.exe`
2. Double-click to run
3. **DWSIM**: .NET Framework 4.x pre-installed on Windows 10/11 — DWSIM works out of the box

### macOS
1. Download `KASP v2.0.0.dmg`
2. Drag `KASP v2.0.0.app` to Applications
3. **First launch:** Right-click → Open → Open (Gatekeeper bypass)
4. **DWSIM**: Requires Mono/.NET SDK installed separately
