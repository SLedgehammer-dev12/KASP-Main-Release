# KASP v2.0.4 — Ortak Faz Sınıflandırması & Log Stabilitesi

---

## 🇹🇷 Türkçe

### 🧪 Ortak Faz Sınıflandırması (Yeni)
- **Tüm EOS motorları için tek `_classify_phase(Z, D, raw_phase)` fonksiyonu**
- Z-faktör ve yoğunluğa dayalı tutarlı faz tespiti: `Z > 0.7` veya `D < 100 → gas`, `0.3 < Z ≤ 0.7 → supercritical`, `Z ≤ 0.3 → liquid`
- EOS'lar arası faz tutarsızlığı giderildi (CoolProp "supercritical_liquid", diğerleri "gas" gibi)
- Ham faz bilgisi `raw_props['raw_phase']` altında debug için korunur
- `'twophase'` (CoolProp) string mismatch düzeltildi → `'two-phase'` olarak normalize edildi

### 🔧 CoolProp Faz Tespiti Güçlendirildi
- **`PhaseSI` yerine `AbstractState.phase()` kullanılıyor**
- Karışımlar için faz zarfı otomatik yönetilir, "phase envelope must be built" hataları önlenir
- `AbstractState` örneği karışım başına cache'lenir — performans kaybı yok
- İsentropik flash fallback: PropsSI başarısız olursa AbstractState ile tekrar dene

### 📊 Belirsizlik Analizi (Uncertainty) Çalışır Hale Getirildi
- **Bug fix:** `lambda _: results["actual_poly_efficiency"]` yerine gerçek re-calc closure
- Her parametre (`p_in`, `p_out`, `t_in`, `flow`) için central difference ile sensitivity hesaplanır
- Recursion guard: `enable_uncertainty=False` ile alt hesaplamalarda belirsizlik analizi atlanır

### 🤫 Log Spam Azaltımı
- **CCP/AGA8/DWSIM eksikliği artık WARNING değil INFO seviyesinde loglanır**
- Beklenen konfigürasyon durumları (opsiyonel kütüphane yüklü değil) artık kullanıcıyı alarma geçirmez
- EosChain post-processing'e de taşındı — gereksiz fallback girişimleri önlenir
- Grafik oluşturmada etkin EOS kullanılır (fallback sonrası kilitlenen EOS)

### 🔬 Metot 4 Faz Zarfı Uyarısı
- Metot 4 sonucu k-tabanlı referanstan %3'ten fazla saparsa WARNING loglanır
- `history` dict'ine `phase_boundary_warning`, `t_out_kbased_ref`, `deviation_pct` eklenir

### 🛠️ Diğer Düzeltmeler
- **Engineering tablosu artık en az 5 satır görünür** — `setMinimumHeight(220)` ve satır içi scrollbar kapatıldı
- Dinamik satır ekleme sonrası `resizeRowsToContents()` + `updateGeometry()` çağrıları eklendi
- `Ignoring fixed y limits to fulfill fixed data aspect` matplotlib uyarısı filtrelendi
- `_active_eos_chain` post-processing sırasında korunur, gereksiz fallback girişimi engellenir
- Sonuç dict'ine `_effective_eos` eklenir (grafik ve raporlama için)

## 🇬🇧 English

### 🧪 Unified Phase Classification (New)
- **Single `_classify_phase(Z, D, raw_phase)` for all EOS engines**
- Consistent Z-factor & density-based phase detection: `Z > 0.7` or `D < 100 → gas`, `0.3 < Z ≤ 0.7 → supercritical`, `Z ≤ 0.3 → liquid`
- Cross-EOS phase inconsistency fixed (e.g. CoolProp "supercritical_liquid" vs others "gas")
- Raw phase preserved in `raw_props['raw_phase']` for debugging
- `'twophase'` (CoolProp) string mismatch fixed → normalized to `'two-phase'`

### 🔧 CoolProp Phase Detection Hardened
- **`AbstractState.phase()` replaces `PhaseSI`**
- Phase envelope auto-managed for mixtures — "phase envelope must be built" errors eliminated
- AbstractState cached per mixture — zero performance penalty
- Isentropic flash fallback: retry with AbstractState when PropsSI fails

### 📊 Uncertainty Analysis Now Functional
- **Bug fix:** Real recalculation closure replaces stub `lambda _: results["actual_poly_efficiency"]`
- Central difference sensitivity computed for each parameter (p_in, p_out, t_in, flow)
- Recursion guard: `enable_uncertainty=False` skips nested uncertainty computation

### 🤫 Log Spam Reduction
- **Missing CCP/AGA8/DWSIM now logged at INFO level, not WARNING**
- Expected configuration states (optional library not installed) no longer alarm users
- EosChain propagated to post-processing — prevents unnecessary fallback attempts
- Graph generation uses effective (post-fallback) EOS

### 🔬 Method 4 Phase Boundary Warning
- WARNING logged when Method 4 deviates >3% from k-based reference
- `phase_boundary_warning`, `t_out_kbased_ref`, `deviation_pct` added to history dict

### 🛠️ Other Fixes
- **Engineering table now shows minimum 5 rows** — `setMinimumHeight(220)`, internal scrollbar disabled
- `resizeRowsToContents()` + `updateGeometry()` called after dynamic row insertion
- `Ignoring fixed y limits to fulfill fixed data aspect` matplotlib warning filtered
- `_active_eos_chain` preserved during post-processing, preventing redundant fallback
- `_effective_eos` stored in results dict (for graph generation & reporting)
