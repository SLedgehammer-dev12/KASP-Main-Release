## 🇹🇷 Türkçe

### 🧠 Stage Lock-in (Yeni)
- **EosChain artık stage içinde EOS değiştirmiyor**
- İlk başarılı `get_properties` çağrısında EOS kilitlenir, tüm stage boyunca aynı EOS kullanılır
- Kilitli EOS kırılırsa `EosChainBrokenError` fırlatılır, stage otomatik yeniden başlatılır (max 2 deneme)
- Ardışık `get_properties` çağrılarında farklı EOS'ların kullanılmasından kaynaklanan entalpi tutarsızlıkları engellenir
- T_out=1460°C gibi sapmalar artık oluşmaz

### 🔄 Metot Fallback (Yeni)
- **Metot 4 (Doğrudan H-S) → Metot 1 (Ortalama Özellikler) otomatik fallback**
- `method_direct_hs` yakınsamazsa veya `RuntimeError` fırlatırsa `method_average_fn` ile devam eder
- `history` dict'ine `fallback_from_method`, `fallback_to_method`, `fallback_reason` alanları eklenir
- Kullanıcıya WARNING log ile bilgi verilir

### ⚡ Performans
- **PR/SRK EOS'lar için `HeatCapacityGases` integral cache**
  - `_h_int_cache` dict ile 0.1K hassasiyette sıcaklık bazlı önbellekleme
  - Metot 1 iterasyonlarında yakın T değerleri için %90+ cache hit
  - Tahmini performans iyileşmesi: PR hesaplamalarında 10x hızlanma

### 🖥️ Engineering Dashboard

#### İki Katmanlı EOS Shootout
- **Üst tablo (5 kolon, scroll yok):** EOS | Durum | T_out (°C) | Head (kJ/kg) | Power (kW)
  - Tüm EOS'lar tek seferde görünür, yatay scroll gerekmez
- **Alt panel (seçili satır detayı):**
  - 🔄 Fallback zinciri (hangi EOS'tan hangisine düşüldüğü + sebep)
  - 🔍 Giriş/Çıkış ham özellikleri: MW, k, Z, Cp, Cv, yoğunluk, faz
  - ⏱️ Süre, η_poly, Head Δ%

#### Daraltılabilir Paneller
- **`CollapsibleGroupBox`** — tüm Engineering panelleri tıklanarak gizlenebilir/gösterilebilir
- Uzun dashboard sayfasında kullanıcı sadece ilgilendiği panele odaklanabilir

### 🐛 Düzeltmeler
- **CCP import:** `import ccp` modül seviyesine taşındı, `CCP_LOADED` flag'i eklendi
- **Çift WARNING:** EosChain aktifken eski fallback path artık `logger.debug` kullanır
- **matplotlib DEBUG spam:** `logging.getLogger('matplotlib').setLevel(WARNING)`
- **ccp min versiyon:** `ccp>=0.1.5` → `ccp>=0.3.0` (pkg_resources-free)
- **`_solve_fallback` H referansı:** 273.15K → 298.15K

## 🇬🇧 English

### 🧠 Stage Lock-in (New)
- EosChain no longer switches EOS mid-stage
- First successful EOS is locked, used throughout the entire stage
- Locked EOS failure triggers stage restart (max 2 retries)
- Prevents enthalpy inconsistencies from mixed-EOS calculations

### 🔄 Method Fallback (New)
- **Method 4 (Direct H-S) → Method 1 (Average Properties)** automatic fallback
- Triggers on non-convergence or RuntimeError
- `fallback_from_method`, `fallback_to_method`, `fallback_reason` added to history

### ⚡ Performance
- **PR/SRK HeatCapacityGases integral cache**
  - 0.1K-resolution temperature-based caching for Cp polynomial integration
  - ~10x speedup for PR calculations

### 🖥️ Engineering Dashboard
- **Two-layer EOS Shootout:** 5-column summary + expandable detail panel
- **Collapsible panels** for all dashboard sections

### 🐛 Fixes
- CCP import moved to module level with `CCP_LOADED` flag
- Duplicate WARNING eliminated when EosChain is active
- matplotlib DEBUG spam suppressed
- CCP minimum version bumped to 0.3.0
